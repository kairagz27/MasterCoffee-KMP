# Проверяемые ограничения интерфейса

- Рабочая поверхность: кабинет смены, в первую очередь очередь заказов и серверная сумма. Основные действия — подтверждение оплаты и следующий допустимый статус.
- Очередь использует серверные страницы по 50 заказов с переходом к более ранним и возвратом к новым. На время поиска выбранный заказ и его денежные действия очищаются; ошибка QR не оставляет оплату прежнего заказа.
- Пользователи: сотрудники одной кофейни и администраторы каталога. Вход клиента завершается сообщением об отсутствии доступа.
- Визуальная основа: существующие MasterTeal (#2A7E87, затемнённый для контраста текста), Montserrat и логотип из мобильного приложения. Спокойный плотный интерфейс с чёткими разделителями; светлая/системная тёмная тема.
- Целевые размеры: 390x844 и 1440x900. На узком экране очередь и детали идут последовательно, формы не требуют горизонтальной прокрутки. Все основные элементы имеют цель касания минимум 44 px.
- Клавиатура: нативные формы, кнопки, select и dialog; видимый фокус, skip-link, связанные подписи; сообщения через role=status/alert. Dialog закрывается Escape и восстанавливает фокус средствами браузера.

| Состояние | Триггер, обратная связь и следующий шаг |
| --- | --- |
| Загрузка | Вход, каталог, очередь или операция: подпись/aria-busy, повторное действие блокируется до ответа |
| Пусто | Нет заказов или stories: сообщение с обновлением/созданием |
| Ошибка | Ошибка API/сети/тайм-аут: явное сообщение без локального успеха, обновление или повтор после проверки данных |
| Частичные данные | Polling не удался: остаются последние данные с явной отметкой; обновление вручную |
| Успех | Ответ mutation от сервера: новый фактический статус/сумма и подтверждение операции |
| Права | Роль customer, 401, 403 или отсутствие камеры: объяснение, повторный вход или ручной код |

Фактические результаты визуальной проверки и ограничения записываются отдельно; этот контракт сам по себе не подтверждает проверку.
