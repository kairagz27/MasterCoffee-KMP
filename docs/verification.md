## Среда и оставшиеся ограничения

Локальный C: заполнился при первых сборках и запуске Docker/AVD; PostgreSQL внутри Docker получил read-only filesystem. После освобождения памяти и штатной Gradle clean появился запас места, но Docker Desktop затем отказался стартовать из-за недоступного временного `sailor-ingest.sock.stale`. Factory reset, удаление volumes и чужих данных не выполнялись. Docker Compose проверен в чистой Linux CI среде; локальная Windows-инсталляция Docker остаётся внешним блокером.

Пользователь разрешил очистку воспроизводимых кешей. Автоматическая проверка исполнения отклонила команды удаления Gradle-кешей сообщением `blocked by policy`, в том числе с явным абсолютным путём; обходов удаления не выполнялось. Удалось применить штатную Gradle clean и снизить потребление памяти. Последующие сборки выполнялись последовательно с single-use JVM 768 МиБ, in-process Kotlin, одним worker и test JVM 128 МиБ.

Для независимых проверок создан временный локальный PostgreSQL 18 cluster под игнорируемым `artifacts/postgres18`, только loopback 55433; Go API — 8080, локальный Node cabinet — 8081. Это тестовый стенд с демонстрационными данными. Восстановленная отдельная БД использовалась с API 8082 и затем остановлена. Исходный установленный PostgreSQL service и его данные не изменялись.

Production release не собран и не опубликован. Остаются macOS/iOS, физический Android и камера/TalkBack, почтовое подтверждение/reset, staff provisioning, HTTPS/секреты/monitoring/retention, возвраты и нагрузочное тестирование. Не настроены платные SMS, online payment или перенос живых Firebase-данных.

Ветка `codex/local-mvp`; [draft PR #1](https://github.com/kairagz27/MasterCoffee-KMP/pull/1). Main не изменялся, merge не выполнялся, существующая история не переписывалась.
